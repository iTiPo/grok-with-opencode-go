# Grok with OpenCode Go

## Why?

Grok Build uses significantly fewer resources, but you prefer the OpenCode Go subscription. This Dev Container feature bridges that gap, allowing you to use Grok Build while maintaining your OpenCode Go subscription.

## How

For detailed usage instructions, see [`src/grok-with-opencode-go/README.md`](src/grok-with-opencode-go/README.md).

## FAQ

**What if I want more models?**
> Create an issue or pull request to request additional models.

**Will you support automated sync with models at models.dev?**
> Yes, support for automated sync is planned for future releases.

**Will you support other providers?**
> Yes, support for other providers is planned for future releases.
